# Godot Lessons: Beginner to Game Dev — Second Edition

GDScript projects from **Godot Lessons: Beginner to Game Dev — Second Edition** by Brad Bigner (Boing Labs).

Every folder below is one DIY project from the book. Each folder holds the
complete scripts for that project — the same code printed in the book's
appendices. Open a folder's scripts in Godot 4.6 and follow the book's steps
to build the scenes they attach to.

## How to use

1. Install Godot 4.6.
2. Pick a project above and follow its chapter in the book: create the Godot
   project, build the scenes exactly as the chapter says, then attach the
   scripts from the matching folder.
3. Art, sounds, and sprite sheets come from your own project setup, as the
   book explains in each chapter — this repo holds the code, not the art.

## A note on the code

These scripts were rebuilt from the book's printed code. They have not all
been playtested in the editor yet — if a value feels off, the book's Tweaks
table for that project is the place to tune it. A small number of constant
values were reconstructed from the book's prose where the original print lost
them; those are the first things to check if a project behaves oddly.
